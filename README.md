# Configurable Subsidies

**Configurable Subsidies** is an OpenTTD Game Script that supplements the game's built-in subsidy system by generating additional subsidy offers at configurable intervals.

The script works alongside vanilla subsidies rather than replacing them. It gives players more opportunities to establish new cargo routes, connect industries, and serve towns.

## Features

- **Additional subsidy offers** generated automatically throughout the game.
- **Configurable generation frequency**, using either months or weeks.
- **Configurable maximum distance** between subsidy source and destination.
- **Configurable target number of outstanding offers** maintained by the script.
- **Save/load support**, preserving the script's tracking data and generation schedule.
- **Shared subsidies** that any company can compete to fulfil.

## Configuration

All settings can be adjusted in-game through the Game Script settings.

### Maximum Subsidy Distance

**Setting:** `max_distance`
**Default:** `500` tiles
**Range:** `0–1,048,576`

Sets the maximum permitted distance between the source and destination of a generated subsidy.

- `500` — generated subsidies are limited to routes no longer than 500 tiles.
- `0` — disables the distance limit.

This setting affects subsidies generated by Configurable Subsidies, not vanilla subsidies.

### Generation Interval

**Setting:** `generation_interval`
**Default:** `3`
**Range:** `1–48`

Controls how frequently the script attempts to generate a new subsidy offer, provided the number of outstanding offers is below the configured target.

The unit is determined by the **Use Weeks Instead of Months** setting.

### Use Weeks Instead of Months

**Setting:** `use_weeks`
**Default:** `Disabled`

Determines the unit used by the Generation Interval setting.

- **Disabled:** the interval is measured in months.
- **Enabled:** the interval is measured in weeks.

For example, an interval of `3` means approximately three months when disabled, or three weeks when enabled.

When using months, the script approximates each month as 30 days.

### Target Outstanding Offers

**Setting:** `target_offers`
**Default:** `10`
**Range:** `0–20,000`

Sets the target number of **unawarded subsidy offers generated by this script** that should remain outstanding.

The script attempts to generate offers only when its tracked outstanding offers are below this target. It makes at most one generation attempt per scheduled interval.

- `10` — aims to maintain up to 10 outstanding script-generated offers.
- `0` — disables the generation of new offers.
- Higher values allow more outstanding offers to accumulate.

This is a target rather than a guarantee: suitable routes must exist, and an offer may not be generated successfully on every attempt.

Only offers generated by Configurable Subsidies count towards this target. Vanilla offers and awarded subsidies do not count towards it.

There is no script-imposed limit on the number of awarded subsidies accumulated over the course of a game, although OpenTTD's own limits still apply.

## How It Works

1. When the script starts for the first time, it immediately attempts to generate a subsidy offer.
2. It schedules subsequent generation attempts according to the configured interval.
3. Before each scheduled attempt, it reconciles its tracked offers and removes offers that are no longer outstanding.
4. If the number of outstanding script-generated offers is below the target, it attempts to create one new offer.
5. If no suitable route can be found, it waits until the next scheduled interval before trying again.

Generated offers are shared across all companies. Any company can compete to fulfil them.

The script uses OpenTTD's normal subsidy expiry behaviour; it does not impose a separate expiry period.

## Save Games

The script saves its own tracking information and next scheduled generation date. When a save is loaded, it can resume its existing schedule rather than restarting the generation interval.

If the script has never run in a save before, it has no saved generation date and will attempt to generate an offer when it starts. This does not guarantee that an offer will be created, as the route and target requirements must still be satisfied.

## Installation

1. Download the release package.
2. Install the Game Script using OpenTTD's supported Game Script installation method.
3. Enable **Configurable Subsidies** in the Game Script settings when starting a game.
4. Adjust the settings to suit your preferred gameplay.

Availability and installation options may vary depending on your OpenTTD version and how the script is distributed.

## Compatibility

- **Game:** OpenTTD
- **Script API:** 15
- **Type:** Game Script

The script supplements the vanilla subsidy system and is intended to run alongside it.
